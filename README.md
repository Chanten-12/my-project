# Nekonečné možnosti – web vysokovibračních olejových parfémů

Jednostránkový web (`index.html`) pro parfémy **Nekonečné možnosti** od Dagmar Chanten.
Nepotřebuje žádný server ani instalaci – stačí soubor otevřít v prohlížeči nebo nahrát na hosting
(např. GitHub Pages, Netlify, nebo jako podstránku na zahranicereality.cz).

## Co stránka obsahuje
- Úvod s mottem „Vůně, která nerozhoduje za tebe…“
- Popis parfému (vysokovibrační, frekvence, krystal, nosný olej jojoba/makadamie)
- Kdy parfém použít
- Kolekci všech vůní s vyhledáváním a záložkami:
  - Variace č. 1–32
  - Peace Inside P1–P4
  - Deep Codes DC 1–DC 9
  - Limitovaná edice LI 1–LI 2
- Postup objednávky (vyber vůni → formulář → platba QR kódem)
- Kontakt a tlačítka „Objednat“ všude, která vedou na Google formulář

## Jak upravit
- **Odkaz na objednávku**: v `index.html` najděte `ORDER_URL` a případně vložte odkaz
  z Google Formulářů (Odeslat → ikona odkazu).
- **Vůně**: seznam je v `index.html` v proměnné `EDITIONS` – stačí přidat/smazat řádek.

## Podklady (Google Drive)
- Parfémy (Dokument A5) Nekonečné možnosti.pdf – hlavní popis

- Parfémy obě strany _ čísla parfémů.pdf, Parfémy čísla parfémů a variace (2_část).jpg – č. 1–32, P1–P4
- Parfémy Limitovaná edice.png, Parfémy AKTUALIZACE.pdf – LI a Deep Codes
